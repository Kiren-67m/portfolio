## Work on this site

The site uses HTML, CSS and JavaScript, with no build step. Open `index.html` directly for a quick preview, or serve the repository locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`. The page loads fonts and icon/style libraries from CDNs.

| File | Purpose |
| --- | --- |
| `index.html` | Page content and project links |
| `styles.css` | Layout and visual styles |
| `script.js` | Navigation and interactive behavior |

Project code, methods and limitations are documented in each linked repository.
